Cách đưa trang web lên GitHub Pages

  1. Tạo Repository mới: Đăng nhập vào GitHub, nhấn New repository, đặt tên (ví dụ: ai-domains) và chọn chế độ Public.
  2. Tổ chức cấu trúc thư mục: Đặt file index.html ở thư mục gốc, cùng cấp với thư mục videos/ chứa đầy đủ 7 file từ video_1.mp4 đến video_7.mp4. 
    📁 ai-domains/
 ├── 📄 index.html
 └── 📁 videos/
      ├── 🎬 video_1.mp4 (Sản xuất)
      ├── 🎬 video_2.mp4 (Giao thông)
      ├── 🎬 video_3.mp4 (Thương mại điện tử)
      ├── 🎬 video_4.mp4 (Trợ lí ảo)
      ├── 🎬 video_5.mp4 (Giáo dục)
      ├── 🎬 video_6.mp4 (Tiếp thị)
      └── 🎬 video_7.mp4 (Y tế)
  3. Bật GitHub Pages: Vào mục Settings → Pages (cột bên trái). Tại mục Branch, chọn nhánh main (thư mục /root) và nhấn Save.
  4. Hoàn tất! Sau khoảng 1 phút, GitHub sẽ cung cấp đường dẫn trang web trực tuyến dạng https://ten-cua-ban.github.io/ai-domains/ để bạn chia sẻ.
